# Markdown 周刊输出格式

## 使用时机

所有周刊输出都使用此 Markdown 格式。适用于 jinzheio Astro 博客发布和公众号图文转换。

## 文件路径

`src/content/blog/paid-traction-weekly-{week}.md`

例：`src/content/blog/paid-traction-weekly-12.md`

## Frontmatter

```yaml
---
title: "增长产品每周观察 · WEEK {week}"
description: "{n} 个一人公司可借鉴方向 —— 它们不一定是融资新闻里的明星公司，但都有可观察增长和适合一人公司借鉴的产品切口。"
pubDate: {YYYY-MM-DD}
tags:
  - 增长产品
  - 一人公司
  - 产品观察
  - 周刊
draft: false
---
```

## 封面区块

周刊正文以封面信息开头：

```markdown
# 增长产品每周观察

**PAID TRACTION RADAR · WEEK {week}**

{n} 个一人公司可借鉴方向

它们不一定是融资新闻里的明星公司，但都有可观察增长和适合一人公司借鉴的产品切口。

---

2026 · WEEK {week}  @金哲 Dev
```

## 产品条目模板

每个产品使用统一结构：

```markdown
## {rank}. {产品名}

![{产品名}截图](/images/weekly/{week}/{domain-slug}.png)

**{domain}** · 上线 {year}年{month}月 · 推荐指数 {score}

{一句话 thesis —— 产品卖什么、用户是谁}

### 用户是谁

{2-4 句，写具体用户和场景}

### 付费场景

{2-4 句，写用户在什么情况下掏钱}

### 技术原理

{2-4 句，写产品怎么做到的，关键能力是什么}

### 流量方法

{2-4 句，写主站流量来源和获客证据}

---

> 付款行为 {模糊数字} · 付款行为增长 {rounded}%
```

## 条目规则

- 排名从 1 开始连续编号。
- 产品名使用官网显示的品牌名，不要翻译。
- domain 写完整域名，不带 `www.`。
- 上线时间从注册日期推算，写 `{year}年{month}月`，例如 `2025 年 03 月`。注册日期缺失时写 `未公开`。
- 推荐指数显示四舍五入整数，满分 100。
- thesis 一句话说清产品卖什么，不超过 40 字。
- 四个板块每个 2-4 句，写具体事实和场景。板块内容不足时宁可短，不用空泛描述填充。
- 付款行为数字必须模糊化：`10,351` → `1 万+`，`23,631` → `2 万+`。不展示精确值。
- 付款行为增长超过 50% 时显示百分比；不超过 50% 时，仅当付款行为超过 10000 时显示付款行为本身，不显示增长百分比。
- 截图路径为 `/images/weekly/{week}/{domain-slug}.png`，其中 `{domain-slug}` 是域名去掉后缀并将点替换为连字符，例如 `saveai-net.png`。
- 产品之间使用 `---` 分隔。

## 图片规则

- 图片放在 `public/images/weekly/{week}/` 目录。
- 使用真实首页截图，不是卡片或占位图。
- Markdown 中使用标准 `![](path)` 语法。
- 每个产品配一张截图，放在产品名下方。
- 截图宽度建议 1200px，文件格式 PNG。
- 文件名用域名 slug：`{domain-slug}.png`。

## 结尾

```markdown
---

*增长产品每周观察 · WEEK {week} · 完*

*@金哲 Dev*
```

## 公众号适配要点

Markdown 格式同时面向公众号发布，注意：

- 不使用 HTML 标签，纯 Markdown。
- 图片先上传到公众号素材库，替换为公众号图片链接。
- 公众号不支持 `---` 分隔线时，改用空行或简短符号分隔。
- 引用块 `>` 在公众号中可能不显示，可改为加粗或独立段落。
- 如果需要付费可读版本，把封面目录（产品概览列表）放在全文最后，不在开头暴露完整榜单。

## 内容复用

如果已有之前的周刊成稿（HTML 或其他格式），直接复用其中的文案和图片，转换格式即可。不重新做数据筛选、文案生成或合规判断。转换时只做：

- 读取现有产品顺序和字段。
- 保留文案内容不变。
- 按 Markdown 模板重新组织结构。
- 更新 frontmatter 和日期。
- 将图片复制到 jinzheio 对应目录。
